## Reporting a Vulnerability

We take the security of AuraDent and our patient data very seriously. If you discover a security vulnerability within this project, please follow the guidelines below to report it responsibly.

### Where to Report
Please **do not** report security vulnerabilities through public GitHub issues, pull requests, or discussions. Instead, please report them directly via private communication channels or email to the project maintainer:

* **Primary Maintainer:** Chenitha Wijerathna
* **Email:** chenithavindiya@gmail.com

### What to Include in the Report
To help us triage and resolve the issue as quickly as possible, please provide the following details:
* Type of vulnerability (e.g., SQL Injection, XSS, broken access control on admin endpoints, Spring Security bypass).
* Step-by-step instructions or proof-of-concept code to reproduce the issue.
* Affected components, controllers, or database entities.

### What to Expect
* **Acknowledgment:** You can expect an initial response acknowledging receipt of your report within **48 hours**.
* **Updates:** We will provide regular status updates as we investigate and develop a fix.
* **Resolution:** Once the vulnerability is validated and a patch is released, we will credit you for the discovery (unless you prefer to remain anonymous).
